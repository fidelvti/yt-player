yt-player

Tus suscripciones de YouTube, organizadas en listas a tu medida.

Qué es

yt-player es una aplicación personal y de código abierto que cada usuario ejecuta en su propio ordenador. Sirve para ver los vídeos de YouTube de forma más tranquila: sin buscador, sin comentarios y sin distracciones.

Qué hace

  • Lee la lista de canales a los que estás suscrito, con un permiso de solo lectura, para que puedas agruparlos en listas propias.
  • Muestra los vídeos recientes de los canales de cada lista.
  • Reproduce los vídeos con el reproductor incrustado de YouTube, con velocidad ajustable.
  • Genera, a petición del usuario, un resumen de los vídeos seleccionados.

Tus datos

Todo se guarda únicamente en tu ordenador. El autor no recibe ni almacena ningún dato de los usuarios. Consulta la política de privacidad para ver el detalle.

Código fuente

El proyecto es abierto: github.com/fidelvti/yt-player.

yt-player utiliza los servicios de API de YouTube. Al usar la aplicación aceptas las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

Política de privacidad · Código fuente

English: yt-player is a personal, open-source app that runs locally on each user's computer. It reads your YouTube subscriptions (read-only) so you can group channels into lists and watch their latest videos. No user data is collected by the author.
